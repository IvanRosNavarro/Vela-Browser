# Vela v0.1.0 — Primera beta pública

**Fecha:** 2026-05-20  
**Tipo:** Beta pública inicial

---

## Resumen

Primera versión pública de Vela Browser. Funcional y en uso diario, pero en fase beta activa. Espera aristas; [abre issues](https://github.com/IvanRosNavarro/Vela-Browser/issues) si las encuentras.

---

## Características incluidas

### Organización de pestañas
- Sidebar vertical con árbol jerárquico (carpetas, grupos, anidado infinito)
- Drag & drop con `fractional-indexing` para ordenación estable
- Workspaces con nombre, color e icono — CRUD completo
- Ctrl+Tab con modal MRU, scope configurable (workspace / global)
- Favoritos globales por perfil fijados en la sidebar
- Auto-descartado de pestañas inactivas con whitelist de 4 niveles
- Preview de pestaña al hover en la sidebar

### Privacidad y seguridad
- Ad blocker nativo integrado (listas actualizadas cada 24h)
- Gestor de contraseñas AES-256-GCM con auditoría HIBP (k-anonymity)
- Tabs blindadas: sesión en memoria, sin historial, sin capturas, directorio temporal destruido al cerrar
- Denegación silenciosa de notificaciones por defecto
- Cookie Manager nativo con panel flotante
- Scripts de usuario sin acceso a APIs de Electron o Node

### Productividad
- URL bar con modos de prefijo: `>` comandos, `#` historial, `@` tabs abiertas, `!` motores de búsqueda
- Split View horizontal/vertical con layout persistido por workspace
- Glance: preview flotante de un enlace con Ctrl+hover — sesión efímera sin rastro
- Control de multimedia universal desde la barra de título
- Modo lectura con Mozilla Readability (tipografía y tema configurables)
- Captura de pantalla: área visible, selección libre y página completa con editor de anotaciones
- Command Palette `Ctrl+Shift+P` con fuzzy matching y argumentos
- Gestos de ratón configurables

### Personalización
- 8 temas integrados: Vela Claro/Oscuro, Midnight, Solarized, Nord, Dracula, Gruvbox Dark, Sistema
- Editor de temas con preview en vivo — importar/exportar `.vela-theme.json`
- Custom CSS inyectable sobre el chrome del navegador
- URL bar configurable: elige qué iconos aparecen y en qué orden
- Atajos de teclado configurables con hot-reload
- Aparejos: accesos rápidos a páginas y herramientas, izables desde la sidebar

### Sincronización E2EE
- Sincroniza workspaces, árbol de pestañas, favoritos, scripts, notas y el vault de contraseñas
- Cifrado AES-256-GCM con derivación scrypt — el servidor almacena blobs opacos
- Autenticación por magic link — sin contraseñas de cuenta
- Offline-first: los cambios se encolan y se envían al reconectar
- Recovery Card PDF descargada localmente — zero-knowledge by design
- Servidor oficial en `sync.vela-browser.com`; cualquier fork puede levantar el suyo

### Extensiones
- Soporte de extensiones Manifest V3 nativo
- `vela://extensions`: instalar, activar/desactivar, gestionar por perfil — instalación desde `.crx`
- Scripts de usuario nativos (`vela://scripts`) — Userscripts y Userstyles sin extensión adicional

## Notas importantes

- **Beta**: funcional en uso diario, pero puede haber comportamientos inesperados.
- **Auto-update**: versiones posteriores se instalan automáticamente.
- El servidor de sync `sync.vela-browser.com` está operativo; los forks pueden [auto-hospedar el servidor](../../packages/sync-server/.env.example).

## Cambios técnicos desde el estado interno pre-beta

- Historial de git limpiado (orphan branch) para la apertura pública.
- Todos los secretos eliminados del código; configuración vía variables de entorno.
- 6 vulnerabilidades de autorización en el sync-server corregidas.
